# LifeNote Mobile

Flutter app will be implemented after the backend MVP is stable.

Recommended creation command:

```bash
cd apps
flutter create mobile
```

Then use the backend API:

- Web/iOS Simulator: `http://localhost:3000/api/v1`
- Android Emulator: `http://10.0.2.2:3000/api/v1`
- Physical phone: `http://<YOUR_LAN_IP>:3000/api/v1`
